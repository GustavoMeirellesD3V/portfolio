01 — Sobre

Front-end que vai do layout ao deploy

Sou desenvolvedor front-end e trabalho principalmente com HTML, CSS e JavaScript puro — sem framework quando o projeto não precisa de um. Gosto de código enxuto, interface limpa e página que não faz o usuário esperar.

Hoje estou construindo um sistema de agendamento online para uma nail designer, cuidando de tudo: layout, banco de dados, autenticação e publicação. É o tipo de projeto que me interessa — pequeno o bastante para eu fazer inteiro, grande o bastante para exigir decisão.

Moro em Cachoeira Paulista, São Paulo, e estou aberto a freelas, projetos de cliente e oportunidades como front-end júnior.

02 — Projeto

O que eu construí

Carioca e Glow

em produção

Sistema de agendamento online para uma nail designer. A cliente escolhe o serviço, vê os horários livres e marca sozinha, sem troca de mensagem. O salão acompanha a agenda por um painel próprio.

  • Agenda com horários em tempo real, sem conflito de marcação
  • Painel de administração com login protegido
  • Feito para celular primeiro — é de onde vem quase todo agendamento
